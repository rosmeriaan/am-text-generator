Cara import ke Alight Motion
  1. Tap Generate XML lalu Download XML — file tersimpan di folder Download HP kamu.
  2. Buka aplikasi Alight Motion, masuk ke project yang ingin ditambahkan text ini (atau buat project baru).
  3. Buka tab Templates → tombol Upload/+ → pilih file XML yang sudah didownload.
  4. Alternatif: buka File Manager HP → cari file XML-nya → Share → pilih Alight Motion.
  5. Layer per-karakter akan muncul di timeline, siap digeser/disesuaikan.
Catatan: amver/ffver pada XML diambil dari reference AM 3.7.0 (build 166) yang berhasil diverifikasi — versi paling baru yang bisa dipastikan dari dalam APK. Alight Motion pada umumnya backward-compatible dengan project lama, jadi ini pilihan paling aman yang bisa dipastikan tanpa mengarang angka.
